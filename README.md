# HAYWIRE

Мультиплеерная WebGL-игра про самую буквальную иглу в стоге сена.

## Что уже есть

- процедурный WebGL-мир на Three.js: объёмный стог из 30 000 соломинок, смена света, туман, окружение и гусь;
- комнаты с коротким кодом, быстрым входом и приглашением по ссылке;
- до 8 игроков, синхронизация позиций, общий чат, раунды, таймер и таблица очков;
- серверная проверка находки иглы;
- чих-бомба, магнитный импульс и аграрный надзор в лице гуся;
- клавиатура/мышь и базовые мобильные органы управления.

## Локальный запуск

```bash
npm install
npm run dev
```

Игра откроется на `http://localhost:3088`.

## Проверки

```bash
npm run check
npm test
npm run build
```

## Production

Production-сервер запускается командой `npm start` с переменными `NODE_ENV=production` и `PORT=3097`. Примеры Systemd и Nginx лежат в `deploy/`.

Проверка сервиса: `GET /api/health`.
